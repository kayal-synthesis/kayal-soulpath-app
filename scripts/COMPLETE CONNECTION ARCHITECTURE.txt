🔧 How It's Configured
1. Environment Variable
bash
# .env.local
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
NEXT_PUBLIC_WS_URL=ws://127.0.0.1:8000
2. API Client
typescript
// lib/api/client.ts
import axios from 'axios'

const API_BASE = process.env.NEXT_PUBLIC_API_URL || 'http://127.0.0.1:8000'

export const api = axios.create({
  baseURL: API_BASE,  // ALL requests go here
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json',
  },
})
3. Next.js Proxy (Optional)
javascript
// next.config.js
async rewrites() {
  return [
    {
      source: '/api/:path*',
      destination: 'http://127.0.0.1:8000/:path*', // Proxy to FastAPI
    },
  ]
}
🚀 Production vs Development
Environment	API URL	WebSocket URL
Development	http://127.0.0.1:8000	ws://127.0.0.1:8000
Production	https://api.yourdomain.com	wss://api.yourdomain.com
✅ Key Takeaway
YES! Every single backend operation - authentication, user management, report generation, palm reading, face analysis, referrals, payments, admin analytics - ALL go through your FastAPI server at http://127.0.0.1:8000/ during development.

The frontend is just a presentation layer. All the real work happens in your FastAPI backend! 🚀
